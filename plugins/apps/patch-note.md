# apps 플러그인 패치노트

버전이 바뀔 때마다 맨 위에 한 덩어리를 덧붙인다(`/apps:config` "바꿀 때마다"). 이미 쓴 내용은 고치지 않는다.

- **버전 규칙**(2026-11-18 사용자 결정): 스킬을 추가하거나 스킬이 완성되면 가운데 수치(0.3.x → 0.4.0), 만드는 중인 스킬을 고칠 때마다 마지막 수치만(0.4.1, 0.4.2, …)
- **덩어리 형식**: `## 버전 — 날짜 · PC · 커밋` 아래에 해당하는 것만 쓴다
  - **추가** — 새 스킬(무엇을 하는 스킬인지, 추가 사유)과 새 기능
  - **변경** — 어느 스킬의 어느 부분이 어떻게 바뀌었나(바꾼 사유가 있으면 함께)
  - **버그 수정** — 어떤 문제가 있었고 어떻게 고쳤나

0.4.2 이전 내용은 2026-11-18에 git 기록과 `HANDOFF.md` 플러그인 행에서 되살려 적었다.
