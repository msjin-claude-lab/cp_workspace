## 등록 체크리스트 (Play Console 순서)

1. [ ] Play 개발자 계정(개인, 등록비 25달러) — 본인 인증

2. [ ] **앱 만들기**: 앱 이름 `Vocara - 국제 기준(CEFR) 영단어`, 기본 언어 한국어, 앱(게임 아님), 무료, 선언 체크
3. [ ] 개인정보 처리방침을 Google Sites에 게시(`privacy-policy.md` 맨 아래) → 주소 확보
4. [ ] **앱 콘텐츠**(`policy-answers.md` 순서대로)
   - [ ] 개인정보처리방침 주소
   - [ ] 광고: **있음**(2026-11-29 AdMob 배너)
   - [ ] 앱 액세스 권한: 제한 없음
   - [ ] 콘텐츠 등급 설문 — **결과 등급이 13세 미만 대상과 맞는지 확인**(4절 주의)
   - [ ] 타겟층: 6~8 · 9~12 · 13~15 · 16~17 · 18+ (가족 정책)
   - [ ] 데이터 보안: 광고 SDK가 보내는 4가지(IP·앱 상호작용·진단·기기 식별자)를 수집·공유로 선언(`policy-answers.md` 6절)
   - [ ] 가족 정책: "모두 어린이 처리"(나이 확인 화면 없음)가 맞는지 확인(5절)
   - [ ] 정부 앱·금융·건강 등: 해당 없음
5. [ ] **스토어 등록정보**(`listing.md`, `graphics/`)
   - [ ] 앱 이름 · 간단한 설명 · 자세한 설명
   - [ ] 앱 아이콘 `icon-512.png`
   - [ ] 그래픽 이미지 `feature-1024x500.png`

6. [ ] **스토어 설정**: 카테고리 교육, 태그, 연락처 이메일(`listing.md` "그 밖의 항목")

8. [ ] **릴리스**: 처음에는 내부 테스트 트랙에 `app-release.aab` 업로드 → 본인 폰에서 설치 확인 → 프로덕션(개인 개발자 계정은 비공개 테스트 조건이 붙을 수 있다 — 계정 만들 때 안내를 확인)
