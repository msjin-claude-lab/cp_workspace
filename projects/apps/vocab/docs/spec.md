## Goal
초·중·고 학생이 학교급(초/중/고) × 난이도(하/중/상) 9칸의 내장 단어와 직접 만든 단어장으로 카드 학습·4지선다 시험·오답 노트를 하고, 진도를 칸별·날짜별로 보는 안드로이드·iOS 앱.

## Constraints
- 안드로이드·iOS 둘 다 동작
- 단어·뜻·예문·칸 배정은 Claude가 작성해 앱에 내장. 예문은 새로 작성(저작권). 칸마다 표본을 사람이 확인
- 예문마다 우리말 해석을 함께 내장하고, 카드 뒷면·시험 정답 화면에서 예문 아래에 보여 준다. 내 단어장 단어의 예문·해석은 선택(2026-11-20 사용자 결정 — 개발 중 추가)
- 계정·서버 없음, 모든 기록은 기기 안에만
- 플랫폼 기능은 TTS만 사용
- **화면 구조(2026-11-20 사용자 결정 — 개발 중 추가, 같은 날 두 번 고침)**: 학교급 고르기 → 난이도 고르기(선택은 세로 버튼) → 칸 홈(카드 학습·4지선다 시험·오답 노트·칸 바꾸기). 고른 칸(학교급 + 난이도)은 기기에 남아 앱을 열면 그 칸 홈이 바로 뜬다. 칸 홈의 ☰ 메뉴(학교급 ▸ 난이도 2단계)로도 칸을 바꾼다. 안쪽 화면은 ← 뒤로와 ⌂ 홈(칸 홈)을 둔다. 시험 문항 수는 화면에 보이지 않는다
- **오답 노트(같은 날 사용자 결정)**: 칸 홈에서 그 칸의 오답을 연다(최근에 틀린 것부터, 틀린 횟수). 카드로 다시 보기·오답 시험(보기는 칸 전체에서). 단어는 오답 시험에서 맞히거나 사용자가 지울 때만 빠진다 — 카드 학습의 '안다'·일반 시험의 정답으로는 빠지지 않는다
- **시험은 매번 새로 섞고, 난이도와 상관없이 20문항(같은 날 사용자 결정)** — 단어를 영단어 책 수준으로 늘릴 예정이라 "전부" 같은 선택지는 두지 않는다. 방향은 문제마다 무작위, 칸을 누르면 카드 학습·시험 중 고르는 창 — 이 둘은 사용자가 정하지 않아 Claude가 정함(바꾸기 쉬움)
