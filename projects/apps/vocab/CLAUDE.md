### 지금 앱 (모두 사용자 결정)

- **단어장**: 사용자가 "새 등록"으로 만든 이름 있는 단어장(`StudyDeck`, id `deck_<n>`, `lib/data/study_decks.dart`) = 이름 + 바탕 칸(학교급 × 난이도). 같은 학교급+난이도로 여러 개 만들 수 있고 기록·오답 노트·진도는 단어장마다 따로(`cell_id = deck_<n>`). 이름은 20자까지
- **첫 실행**: 시작 화면 → 이름 → 학교급(`/pick`) → 난이도(`/pick/<학교급>`)로 첫 단어장을 만든다. 고른 단어장은 shared_preferences에 남아 다음부터 홈이 바로 뜬다
- **홈(`/`)**: 제목 = 단어장 이름, 그 아래 `초등 [난이도 : 쉬움]` + 단어 수. 버튼은 카드 학습 / 시험 / 오답 노트 · N단어 / 진도 / 설정. 오른쪽 아래 동그란 버튼(`edit_square`, 툴팁 "새 등록") = 항상 새 단어장 만들기
- **☰ 메뉴**: 앱 제목 + 버전(`영단어 v1.0.0`, `lib/app_info.dart` — pubspec `version`과 같아야 하고 시험이 잡음) + 내 단어장 이름 목록(지금 것에 ✓, 누르면 그것이 홈, ⋮ 이름 바꾸기·지우기). 다른 버튼은 없다
- **화면 문구**: "칸"이라는 말은 화면에 쓰지 않는다(개발용 말). 난이도 이름은 쉬움·중간·어려움. 안쪽 화면 제목은 `<단어장 이름> - 카드 학습`·` - 시험`·` - 오답 노트`·` - 오답 시험`·` - 진도`. 안쪽 화면은 ← 뒤로만(홈 버튼 없음 — 시험 결과 화면의 `홈으로`만 예외)
- **카드 학습(`/study/<단어장>`)**: 넘겨 보기만(안다/모른다 없음). 앞면 영단어 + 자동 발음 한 번, 누르면 뒷면 뜻·예문·해석, 이전/다음. 순서는 회차마다 무작위(회차 안에서는 고정), 설정한 장수만큼. "다음"으로 지날 때 `study_log`에 한 줄 — **한 회차에 카드당 한 번**, 다시 하기 때 새로 센다. 오답 노트는 건드리지 않는다
- **시험(`/quiz/<단어장>`)**: 4지선다, 할 때마다 새로 섞고 설정한 문항 수(단어가 적으면 있는 만큼). 방향은 문제마다 무작위, 한 회차에 같은 단어 한 번. 영→뜻만 자동 발음(뜻→영은 발음이 답을 알려 줌). 답하면 정답 초록·고른 오답 빨강 + 단어·뜻·예문·해석. 결과 화면: 점수·퍼센트·틀린 단어 목록, `다시 하기`/`오답 노트 보기`/`홈으로`. 영단어·뜻이 서로 다른 단어가 4개 이상일 때만 낼 수 있다(`quizBlockReason`)
- **오답 노트(`/wrong-notes/<단어장>`)**: **시험에서 틀린 단어만.** 최근순, 틀린 횟수, 지우기(스낵바 `되돌리기`). 빠지는 것은 오답 시험(`/review/quiz/<단어장>`)에서 맞혔을 때와 직접 지울 때만. "카드로 다시 보기"는 없다
- **진도(`/progress/<단어장>`)**: 그 단어장 하나만. "진행 N일차"(처음 공부한 날이 1일차), `외운 단어 N/전체`(외웠다 = 단어별 `quiz_log` 마지막 줄 `MAX(id)`가 맞힘), 월 달력(공부한 날 점, 날짜를 누르면 `카드 N장 · 시험 M/K문제 맞힘` — K는 그날 푼 문제 수. 시험을 안 푼 날은 `카드 N장`만 — 2026-11-22 사용자 결정)
- **단어장 지우기**: 그 단어장의 오답 노트·학습 기록·시험 기록을 함께 지운다(2026-11-22 사용자 결정)
- **설정(`/settings/<단어장>`)**: **단어장마다 따로**(2026-11-22 사용자 결정 — "설정은 그 단어장의 고유 설정"). 카드 학습 단어 수(기본 50)·시험 문항 수(기본 20), 10/20/30/50 또는 직접 입력(1~999), 고르면 바로 그 단어장에 저장. 홈의 `설정`이 지금 단어장의 설정을 열고 제목은 `<단어장 이름> - 설정`. 값은 `study_decks`의 `card_count`·`quiz_count` 열에 있고, 정하는 순서는 고유 값 → 옛 공통 설정값(shared_preferences `card_count`·`quiz_count`, 이제 읽기만) → 기본값(`lib/data/app_settings.dart`의 `resolveCount`, provider `deckSettingsProvider(deck)` — 값 클래스 `DeckSettings`, 기본값·범위는 `lib/data/counts.dart`). 새 단어장은 50/20을 저장하고 시작하고, 7판 전에 있던 단어장(열이 NULL)은 바꾸기 전까지 옛 공통값을 물려받는다
- **도중 나가기**: 학습·시험·오답 시험 도중 ← 뒤로를 누르면 "그만할까요?"(`lib/features/common/leave_guard.dart`). 나가면 다음에는 처음부터. 카드를 한 번이라도 넘겼으면 이전으로 첫 카드에 돌아와도 묻는다
- **폰에 보이는 앱 이름**: `영단어`(임시 — 이름·아이콘은 미정)

### 데이터

- 내장 단어: 9칸 × 50개 = 450개(`assets/words/`). 중등 중·상과 고등 3칸은 사람 표본 확인 없이 에이전트 검토만 받았다
- 기록: sqflite `vocab.db` **7판**(`study_log`·`quiz_log`·`wrong_notes`(기본 키 `cell_id` + `word_id`)·`study_decks`·`app_meta`). 7판은 `study_decks`에 단어장별 설정 열 `card_count`·`quiz_count`(NULL 허용)를 더한 것뿐이다. 옛 판 사용자는 기록을 유지한 채 올라온다 — 옛 등록·고른 칸은 첫 실행 때 "초등 쉬움" 같은 이름의 단어장으로 옮긴다(`migrateLegacy`)
- **6판 이행(2026-11-22 사용자 결정, `_upgradeToV6`)**: ① 오답 노트에서 **지금 노트가 생긴 뒤(`first_missed_at` 이후) 시험에서 틀린 적이 없는** 단어(옛 카드 학습 '모른다')를 지우고, 남은 것의 틀린 횟수·마지막 틀린 시각을 그 시험 오답 기준으로 맞춘다. 등록하지 않았던 칸의 오답 노트도 같이 정리한다(사용자 결정). 기기 시계를 되돌린 적이 있으면 어긋날 수 있다 ② 직접 단어를 넣는 단어장의 표(`word_books`·`book_words`)와 그 기록(`cell_id`가 `book_`로 시작)을 지운다. 실제 DB 시험(`test/data/study_records_test.dart`)은 4판·5판 → 6판의 내용까지, 1판·2판은 판 번호만 본다(3판에서 올라오는 시험은 없음)
- **직접 단어를 넣는 단어장은 없다**(2026-11-22 사용자 결정 — 필요 없음. `/books`·`lib/features/my_words/`·`BookDeck`을 지움). 이름 입력 창은 `lib/features/home/dialogs.dart`. 명세의 해당 항목도 뺌([docs/spec.md](docs/spec.md))
- **등록하지 않았던 칸의 옛 기록은 그대로 둔다**(2026-11-22 사용자 결정) — 칸 id 그대로 DB에 남고 화면에는 안 보인다
- 단어의 예문·해석은 비지 않는다고 보고 화면이 그대로 그린다(직접 단어장을 지우며 빈 줄 분기를 없앰 — `test/data/word_assets_test.dart`가 지킴). 단어 출처를 늘릴 때 유의
