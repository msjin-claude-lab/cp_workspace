# projects/apps/_drafts — 앱 주제 임시 폴더

`/apps:new <주제>`가 주제마다 폴더 하나를 만들어 1~4단계 기록을 쌓는다. 5단계(최종 결정)에서 `projects/apps/<앱>/`으로 옮기고 그 폴더는 지운다. 전체 목록과 상태는 `/apps:view-subjects`로 본다.

## 진행 중

- [vocab](vocab/README.md) — 영단어 앱(초·중·고). 2단계(선택안) 대기

## 후보 (시작 안 함)

`/apps:new <주제>`로 시작하면 여기서 지우고 위로 올린다.

- 캘린더형·기록형 앱 — 2026-11-17 "먼저" 할 후보로 이야기됨
- 게임형 앱 — 2026-11-17 "나중" 후보로 이야기됨
